# Resiconnect — Frontend

Application web de gestion de résidence. Interface moderne et premium pour les résidents et les gestionnaires.

## Technologies
- React + Vite
- React Router DOM
- Axios
- CSS custom (design premium)

## Lancer le projet

```bash
npm install
npm run dev
```

## Comptes de démonstration

## Fonctionnalités

**Résident**
- Connexion sécurisée (JWT)
- Dashboard avec paiements, tickets et annonces
- Signaler un problème
- Consulter les annonces

**Gestionnaire**
- Dashboard global
- Gestion des paiements
- Mise à jour des tickets
- Publication et suppression d'annonces
